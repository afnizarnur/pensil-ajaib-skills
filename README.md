# Pensil Ajaib Skills

Agent skills for writing, reviewing, and validating UX copy on the Pensil Ajaib / Rumah Pendidikan platform, following the Indonesian education copy guidelines.

## Install

```bash
npx skills add afnizarnur/pensil-ajaib-skills
```

Works with Claude Code and other agents supported by the [`skills`](https://skills.sh) CLI.

## Skills

| Skill | What it does |
|-------|--------------|
| [`pensil-ajaib`](skills/pensil-ajaib/SKILL.md) | Generate and audit UI copy (buttons, dialogs, toasts, errors, tooltips, onboarding) across the Murid, GTK, SPM, and MDLP tribes, including tone, glossary, inclusivity (INC) rules, and character limits per component. |

## Updates

This repo is a published copy. The guidelines are maintained in a separate source repo and synced here when they change, so please open an issue rather than a pull request for corrections.
