# 📚 SPM Master Glossary
_Last updated: 12 Feb 2026_

## 📏 Style Standards
- [STD-01] All body text MUST be sentence case. You MUST use **Title Case** for CTA and headings.
- [STD-02] All time MUST follow HH:MM WIB (e.g., 14:30 WIB).
- [STD-03] All currency MUST follow Rp10.000 (no space after Rp).
- [STD-04] All hyphens MUST follow KBBI (e.g., anak-anak, anti-korupsi).

## 📚 Glossary Enforcement
You MUST ALWAYS use preferred terms. You MUST NEVER use avoided terms.

### ❌ Terms to Avoid (Universal)
- [AVOID-01] **"Harus/Wajib"** → gunakan "Lengkapi", "Pastikan" (kecuali konsekuensi fatal)
- [AVOID-02] **"Di sini"** untuk hyperlink → gunakan "Dokumen ini", "Halaman ini"
- [AVOID-03] **"Server error/timeout/bug"** → gunakan "Terjadi kendala sistem"
- [AVOID-04] **"Lihat/Tonton"** → gunakan "Cek", "Pelajari", "Putar"
- [AVOID-05] **"Meminta pertanggungjawaban"** → gunakan "Berkolaborasi dengan"
- [AVOID-06] **Jargon Kemendikbudristek** tanpa konteks operasional
- [AVOID-07] **Overpromise** → hindari "100% aman", "Dijamin untung"
- [AVOID-08] **Bahasa mendikte** → hindari "Anda harus", "Segera lakukan"

### 📝 Special Formats
