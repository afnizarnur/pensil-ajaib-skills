# INC Accessibility Rules Summary
_Last updated: 6 Apr 2026_

Rules from `Core Guidelines/inclusivity-guidelines.md`. Apply to every copy output.

**Precedence:** Core Principles (INC-PR-*) override Category Rules (INC-CAT-*) when conflicts occur.

---

## Core Principles (INC-PR — always apply)

| Rule | Requirement |
|------|-------------|
| INC-PR-01 | Use action verbs: Cek, Putar, Akses — NOT Lihat, Tonton, Baca |
| INC-PR-02 | Plain language — no jargon, slang, or unexplained abbreviations; one idea per sentence |
| INC-PR-03 | Critical information first — especially for errors; no filler before the main issue |
| INC-PR-04 | No color/position/icon-only cues — text must convey meaning independently |
| INC-PR-05 | No stereotypes or assumptions — gender, religion, ethnicity, ability, device, socioeconomics |
| INC-PR-06 | Clear structure — break multi-step processes into steps; show progress |

---

## Category Rules (INC-CAT — apply when relevant)

### Gender & Cultural Neutrality

| Rule | Requirement |
|------|-------------|
| INC-CAT-01 | Gender-neutral professional language — use role name, not gendered title |
| INC-CAT-02 | No religious framing in generic UI — use "libur nasional", neutral greetings |
| INC-CAT-03 | Standard Indonesian — no regional dialects; use diverse names and regions |
| INC-CAT-04 | Avoid legacy English exclusionary terms — e.g. "Didaftarkan" not "Whitelist" |

### Socioeconomic Inclusion

| Rule | Requirement |
|------|-------------|
| INC-CAT-05 | No access/privilege assumptions — no laptop, e-wallet, stable internet, car, or travel assumptions |
| INC-CAT-06 | No deficit framing — specific conditions, not labels like "orang tidak mampu" or "drop-out" |
| INC-CAT-07 | Use specific group names — avoid umbrella terms like "minoritas" |

### Disability Terminology (UU 8/2016)

| Rule | Requirement |
|------|-------------|
| INC-CAT-08 | Use person-first, current terms — "Penyandang Disabilitas [type]"; no "tuna-" prefix; no "Berkebutuhan khusus" |
| INC-CAT-09 | Precise assistive terminology — "Bahasa isyarat" not "Bahasa tangan"; "Alat Bantu Dengar (ABD)" not "Alat tuli" |

### Alt Text (only when generating alt text)

| Rule | Requirement |
|------|-------------|
| INC-CAT-10 | Alt text only when image adds meaning — skip decorative images |
| INC-CAT-11 | Alt text format — sentence case, active voice, ends with period, no abbreviations, not repetitive |
| INC-CAT-12 | Functional images describe purpose, not appearance |

## Quick Validation Checklist

Before finalizing copy, verify:

- [ ] **INC-PR-01**: Action verbs only (no "lihat/tonton/baca")
- [ ] **INC-PR-02**: Plain language, one idea per sentence, no unexplained jargon
- [ ] **INC-PR-03**: Critical info (errors, blocking) placed first
- [ ] **INC-PR-04**: No color/position/icon-only instructions
- [ ] **INC-PR-05**: No gender, religion, ability, device, or socioeconomic assumptions
- [ ] **INC-PR-06**: Multi-step processes broken into steps with progress indicators
- [ ] **INC-CAT-01**: Gender-neutral titles (use role, not Ibu/Bapak)
- [ ] **INC-CAT-05**: No device ownership or access assumptions
- [ ] **INC-CAT-08**: Legal disability terms — no "tuna-" prefix, no "berkebutuhan khusus"
